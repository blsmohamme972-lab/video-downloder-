# Study library

Study packs published here are downloaded automatically by the StreamSave Study player. Each pack is drawings, captions and per-minute questions for one video.

- `index.json` lists the packs.
- Each pack is `<id>.json` (or `<id>.zip`).

See [../STUDY_PACK.md](../STUDY_PACK.md) for the format and how to publish a pack. CI (`StudyLibraryTest`) checks that every listed pack opens in the app.
